10b. HOW TO WORK THE BASELINE DOWN (read before any cleanup PR)
  Baselined entries CAN be cleared in later PRs — that is the point. But:
  - detekt does NOT fail on stale baseline entries. Fixing the code leaves the
    entry behind; the count only drops when the baseline is regenerated.
  - A wholesale `./gradlew detektBaseline` silently RE-FREEZES any new
    violations introduced since, destroying the ratchet.
  - Therefore: clean one module, regenerate only that module
    (`./gradlew :core:scoring:detektBaseline`), and review the diff.
